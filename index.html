Git & One-Click Deployment Guide

Ye platform static production web app ke taur par structured hai. Tum ise GitHub repo me push karke Vercel, Netlify, ya GitHub Pages par 1 minute me live deploy kar sakte ho.

STEP 1: Push to your GitHub Repository (PowerShell)
cd "D:\cpp-linked-list-mastery"
git add .
git commit -m "feat: complete C++ and Java linked list mastery platform"
git remote add origin https://github.com/<your-username>/cpp-linked-list-mastery.git
git branch -M main
git push -u origin main
STEP 2: Instant Deployment (Vercel / Netlify)
# Option A: With Vercel CLI
npx vercel

# Option B: Vercel Web Dashboard
1. Go to https://vercel.com/new
2. Import your GitHub repo "cpp-linked-list-mastery"
3. Click "Deploy" (Zero configuration needed, vercel.json already present!)

Cloud Sync: Local Fallback Mode
Paste your Firebase project credentials below to activate multi-device cloud persistence.
LINE-BY-LINE SETUP GUIDE (FREE TIER • 2 MINUTES):
1. Create Firebase Project: Open console.firebase.google.com, click "Add project", name it myth-dsa-guide.
2. Enable Firestore Database: Left menu -> Build -> Firestore Database -> Click "Create database" -> Select "Start in test mode" -> Done.
3. Enable Google Authentication: Left menu -> Build -> Authentication -> "Get started" -> Select Google provider -> Enable & Save.
4. Copy Web App Config: Project Settings (gear icon) -> General -> Scroll to Your apps -> Click </> Web icon -> Copy firebaseConfig and paste above (or in js/firebase-config.js).
